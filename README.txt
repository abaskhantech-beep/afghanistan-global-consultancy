AFGHANISTAN GLOBAL CONSULTANCY - FREE STATIC WEBSITE

Files:
- index.html: the complete responsive website.

BEFORE PUBLISHING:
1. Open index.html in Notepad.
2. Find YOUR-EMAIL@example.com and replace it with your real email address in BOTH places:
   - footer mailto link
   - const COMPANY_EMAIL = ...
3. Save the file.
4. Double-click index.html to preview it in Chrome.

FREE PUBLISHING OPTION (GitHub Pages):
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new PUBLIC repository, e.g. afghanistan-global-consultancy
3. Upload index.html to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The public address will be shown on the Pages settings screen.

Important:
- No paid .com domain is required. GitHub Pages provides a free github.io address.
- GitHub account and publishing require the user to sign in and click the controls; this package cannot publish to the user's account without their authorization.
- The enquiry form opens the visitor's email app. It does not store form submissions. A backend or form service is needed for automatic online submission.
- Do not advertise certifications, official representation, registrations, or completed projects unless they are real and documented.
